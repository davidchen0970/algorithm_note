## Part 0　如何使用這本 Handbook

### 這一 Part 在做什麼

這一 Part 不是演算法知識的前置考試，而是整本 Handbook 的使用說明。它協助你理解閱讀順序、章節結構、練習節奏，以及遇到不熟悉主題時應如何往前補觀念。先建立使用方法，可以避免把整本書讀成一份需要從頭背到尾的清單。

### 學完後應該能做到

- 理解每章固定結構與閱讀方式
- 依目前程度選擇完整閱讀、主題查找或複習路線
- 建立閱讀、手寫、測試與回顧的循環

### 建議閱讀方式

- 先讀第 0 章，再依需求進入後續 Part。
- 第一次閱讀先掌握主線，不必一次記住所有細節。

### 閱讀時可以反覆問自己

- 這個主題要解決哪一類問題？
- 它成立需要哪些前提？
- 目前維護的 State 或 Invariant 是什麼？
- 如果條件改變，原方法是否仍然成立？
- 時間與空間成本主要來自哪裡？
