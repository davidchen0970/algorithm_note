## Part 11　數學基礎

### 這一 Part 在做什麼

這一 Part 整理演算法題常用的數學工具與隨機化觀念。目標不是建立完整數學理論，而是訓練你把規律、計數、整除、機率與期望轉成可驗證的程式模型，同時留意整數範圍、浮點誤差與隨機方法的保證形式。

### 學完後應該能做到

- 使用 GCD、質數、模運算、快速冪與組合計數
- 辨認可轉成數學公式或週期的問題
- 理解機率、期望值與 Randomized Algorithm 的基本保證
- 避免 Overflow、除法取整與浮點比較錯誤

### 建議閱讀方式

- 先閱讀常用數學，再進入機率與隨機演算法。
- 每個公式都應確認適用條件與型別範圍。

### 閱讀時可以反覆問自己

- 這個主題要解決哪一類問題？
- 它成立需要哪些前提？
- 目前維護的 State 或 Invariant 是什麼？
- 如果條件改變，原方法是否仍然成立？
- 時間與空間成本主要來自哪裡？
