## Part 8　Greedy Algorithm

### 這一 Part 在做什麼

這一 Part 討論每一步做出局部選擇、而且不回頭修正的演算法。Greedy 的難點通常不是程式長度，而是證明局部選擇不會排除全域最佳解。Interval Problems 提供很典型的練習場景，可透過排序、交換論證與維護最佳邊界建立正確性。

### 學完後應該能做到

- 辨認 Greedy Choice 所摘要的資訊
- 使用交換論證、Invariant 或反證說明正確性
- 理解排序在 Greedy 中如何建立可比較順序
- 處理合併、選擇、刪除與排程類區間問題

### 建議閱讀方式

- 先讀 Greedy 基礎，避免把直覺選擇直接當成證明。
- 再用 Interval Problems 練習排序與局部決策。

### 閱讀時可以反覆問自己

- 這個主題要解決哪一類問題？
- 它成立需要哪些前提？
- 目前維護的 State 或 Invariant 是什麼？
- 如果條件改變，原方法是否仍然成立？
- 時間與空間成本主要來自哪裡？
