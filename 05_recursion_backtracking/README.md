## Part 5　遞迴、回溯與搜尋

### 這一 Part 在做什麼

這一 Part 處理以函式呼叫或決策樹探索問題空間的方法。Recursion 重點是函式契約與 Base Case；Backtracking 則在選擇、遞迴與撤銷之間維持 State。這些方法常能直接對應問題定義，但也要留意重複搜尋、剪枝正確性與 Call Stack 深度。

### 學完後應該能做到

- 為遞迴函式寫出清楚的輸入與回傳契約
- 設定能終止問題規模的 Base Case
- 用決策樹理解選擇、遞迴與撤銷
- 使用合法性檢查與剪枝減少搜尋

### 建議閱讀方式

- 先讀 Recursion，確認能追蹤函式狀態。
- 再進入 Backtracking，將遞迴套用到候選選擇。

### 閱讀時可以反覆問自己

- 這個主題要解決哪一類問題？
- 它成立需要哪些前提？
- 目前維護的 State 或 Invariant 是什麼？
- 如果條件改變，原方法是否仍然成立？
- 時間與空間成本主要來自哪裡？
