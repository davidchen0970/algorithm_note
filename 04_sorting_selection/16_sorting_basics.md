## 開始前要知道

- 排序不只是在改變資料順序，也常用來建立單調性、消除搜尋範圍，或讓相鄰元素具備可比較的關係。
- 評估排序方法時，需同時考慮時間複雜度、額外空間、穩定性、資料規模與資料原始分布。
- C++ 範例預設使用 `std::vector<int>`；若討論實務選擇，也會比較 `std::sort`、`std::stable_sort` 與手寫演算法的差異。

## C++ 編譯骨架

```cpp
#include <algorithm>
#include <iostream>
#include <vector>
using namespace std;

int main() {
    vector<int> data{5, 2, 4, 2, 1};

    // 後續將替換為本章對應的完整排序或選擇演算法。
    sort(data.begin(), data.end());

    for (int value : data) {
        cout << value << ' ';
    }
    cout << '\n';
}
```

## 建議測試資料

1. 空陣列與單一元素
2. 已排序與反向排序
3. 全部相同
4. 含大量重複值
5. 含負數、零與極端整數
6. 接近排序完成的資料
7. 能觸發最差分割結果的資料
