## Part 4　排序與選擇

### 這一 Part 在做什麼

這一 Part 不只介紹如何把資料排好，也說明排序如何改變問題結構。排序後，相鄰關係、單調性與分割位置會變得可利用；選擇問題則關注第 k 個元素，不一定需要完成全部排序。學習重點包含穩定性、原地性、比較次數、額外空間與最差情況。

### 學完後應該能做到

- 理解排序的比較模型與常見性質
- 比較基礎排序、Merge Sort、Quick Sort 與非比較排序
- 使用 Divide and Conquer 分割並合併子問題
- 理解 Quick Select 為何不必完成全部排序

### 建議閱讀方式

- 先讀排序基本概念，再比較各演算法。
- 不要只記平均時間，還要檢查穩定性、額外空間與最差情況。

### 閱讀時可以反覆問自己

- 這個主題要解決哪一類問題？
- 它成立需要哪些前提？
- 目前維護的 State 或 Invariant 是什麼？
- 如果條件改變，原方法是否仍然成立？
- 時間與空間成本主要來自哪裡？
