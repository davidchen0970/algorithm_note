## Part 12　題型辨識與解法選擇

### 這一 Part 在做什麼

這一 Part 將前面學過的資料結構與演算法重新整合成解題決策流程。重點不是看到關鍵字就套模板，而是從輸入限制、候選結構、連續性、單調性、重複子問題與圖關係，逐步縮小可能方法，並由暴力解找出真正昂貴的步驟。

### 學完後應該能做到

- 由題目特徵建立候選方法清單
- 使用限制條件排除不適合的複雜度
- 透過決策樹整理選擇依據
- 從暴力解定位重複工作並推導改善方向

### 建議閱讀方式

- 建議在完成主要資料結構與演算法章節後閱讀。
- 卡題時可回到本 Part 重做問題分類，而不是直接尋找答案。

### 閱讀時可以反覆問自己

- 這個主題要解決哪一類問題？
- 它成立需要哪些前提？
- 目前維護的 State 或 Invariant 是什麼？
- 如果條件改變，原方法是否仍然成立？
- 時間與空間成本主要來自哪裡？
