## Part 14　練習與能力建立

### 這一 Part 在做什麼

這一 Part 將知識轉成可長期累積的解題能力。練習不只是增加題數，而是安排難度、記錄卡點、間隔複習、重新獨立完成，並檢查自己能否解釋 State、Invariant、正確性與複雜度。

### 學完後應該能做到

- 建立可持續的練習節奏
- 依能力與題型安排學習路線
- 用完整紀錄區分理解、記憶與獨立解題
- 透過重做與回顧降低相同錯誤重複發生

### 建議閱讀方式

- 先閱讀練習方法，再建立個人 Roadmap。
- 每題使用紀錄模板，定期回顧卡題原因與重做結果。

### 閱讀時可以反覆問自己

- 這個主題要解決哪一類問題？
- 它成立需要哪些前提？
- 目前維護的 State 或 Invariant 是什麼？
- 如果條件改變，原方法是否仍然成立？
- 時間與空間成本主要來自哪裡？
