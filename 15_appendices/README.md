## Part 15　附錄

### 這一 Part 在做什麼

附錄提供跨章節查詢用的速查資料。它們適合在解題、複習與 Debug 時快速確認複雜度、數值邊界、名詞、解法選擇與 C++ 語言細節，不建議完全取代正文中的推導與案例。

### 學完後應該能做到

- 快速比較資料結構與演算法複雜度
- 檢查數值範圍、邊界與型別風險
- 使用檢查表整理解題流程
- 查閱名詞、解法選擇與 C++ 基礎

### 建議閱讀方式

- 遇到特定問題時按需查閱。
- 若速查內容不理解，回到對應正文閱讀完整推導。

### 閱讀時可以反覆問自己

- 這個主題要解決哪一類問題？
- 它成立需要哪些前提？
- 目前維護的 State 或 Invariant 是什麼？
- 如果條件改變，原方法是否仍然成立？
- 時間與空間成本主要來自哪裡？
